## Execution contract

- Eleven initial attempts precede recovery. Every materializable generated
  public failure receives three draws of each F/N/S condition, even with flat,
  empty or unavailable diagnostics. Public success and invalid initial output
  terminate that group's policy. Private test results never trigger calls.
- The full balanced slot order and explicit paired seeds come from the published
  `pilot-design.json`. The adapter must preserve those seeds in the actual wire
  body; its older generic seed derivation is superseded only for this new study.
- The exact frozen runtime is the current CPython 3.13.12 binary under the native
  macOS sandbox, with five-second wall and two-second CPU limits per case. The
  frozen monitoring coverage backend records line presence. No interpreter,
  verifier, source or provider substitution is allowed after the freeze.
- Qwen and earlier Gemma banks remain closed. This new study uses only Gemma 3
  4B, Parasail/BF16, temperature 0.7, 65536 reserved input tokens and 4096 output
  tokens, JSON-object response mode, no fallback. One request is in flight, with
  at least 60 seconds between admissions. SSE has an 8 MiB wire cap, 180-second
  socket idle timeout and 300-second wall checks at read boundaries (not a hard
  cancellation deadline). A blocking read may overrun by the idle timeout.
- Read-only provider preflight checks endpoint identity, parameters, context,
  price ceilings and available balance. It does not issue a generation probe,
  infer a reset of historical 429 limits, persist account identity or rotate keys.
- A process budget lock and exclusive single-use study claim prohibit duplicates
  and resumption. The research state records the active PID, current charges and
  pending reserves. A terminal error preserves all observations and stops calls.
  A rejected over-limit prompt is a missing selected opportunity, never silently
  truncated or replaced. Complete invalid model output remains a paid failure.

## Durable observations and terminal evaluation

Every native invocation has a durable start and finish/error record, including
source/input hashes, public phase, raw observations, coverage and time. Partial
phases keep their completed executions; unknown execution counts or durations
are not treated as zero. Each response is saved and settled before parsing or
verification. A later local error cannot erase a paid response or authorize a
replacement call. Incomplete phase materialization is disclosed by the audit.

After the model process terminates, a separate `verify` operation replays each
settled valid artifact on public tests and runs its private evaluator cases. It
uses no provider and records a separate execution journal. Public replay
disagreements remain visible, preserve the original stopping decision and make
the evidence gate inconclusive. A previously observed public failure is never
promoted into a success solely because a replay passes. Raw received artifacts,
not upstream references or silently repaired model text, are evaluated.

The audit binds every admitted/settled ID, raw and normalized receipt, native
usage, actual provider request, exact public projection, shared checkpoint,
single acquired snapshot, decoded artifact, test result and execution record.
It reconstructs all eleven initial rows and every eligible three-arm/three-draw
opportunity. It retains all twelve original source-group decisions. Fewer than
six generated failures, nonrepeatable primary gain, a feedback regression or
missing evidence cannot advance to replication planning.

Cost reporting distinguishes actual collection work from nine hypothetical
fixed-policy paths (three arms by three draws). Each path pays its common initial
work and its full diagnostic acquisition, without dividing acquisition cost by
three research draws. Dollars, provider latency and local execution counts/time
remain separate measures. Private evaluation and independent replay are research
costs, never feedback available to the deployed policy. No equal-total-resource
advantage or selector is demonstrated by this information-value pilot.
