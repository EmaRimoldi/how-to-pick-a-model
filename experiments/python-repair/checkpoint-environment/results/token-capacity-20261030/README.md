# Local token capacity before a new diagnostic experiment

The historical 4096-token response ceiling cannot contain the complete original
Black/13 fix in the existing JSON replacement format: its compact encoding is
**5817 tokens**, before the end-of-turn token. This is an interface-capacity
finding, not a model repair result. A shorter correct implementation might fit;
we have not established a minimum length for every valid solution.

The audit retains all six qualified development components, both original and
reference sources, compact and indented JSON. No candidate is dropped. Counts
use the official [Qwen3-Coder-Next tokenizer](https://huggingface.co/Qwen/Qwen3-Coder-Next/tree/a7fbcb5c0e12d62a448eaa0e260346bf5dcc0feb)
at revision `a7fbcb5c0e12d62a448eaa0e260346bf5dcc0feb`, with no added special
tokens during encoding. Output-capacity checks add one end-of-turn token.

An **8192-token candidate ceiling** contains every measured serialization. It is
not frozen for collection, and does not guarantee compliance, sufficient space
for other solutions, or capacity on additional tasks. Future cohorts and actual
generated checkpoints require the same audit. We retain the full-file contract
rather than changing the output format and diagnostic treatment simultaneously.

For the one existing package triplet, the complete official chat-template inputs
contain **7856 / 14606 / 14605 tokens** for feedback / neutral / scored. Both
published template variants and an independently constructed system/user framing
agree. Neutral/scored are one token apart here, not universally token-matched.
The largest measured prompt plus 8192 response tokens is 22798 tokens.
These are local counts, not observations of the provider's template or billing.
The other five components do not yet have new package diagnostic prompt banks;
their input capacity is **not** certified by this report.

## Budget consequence, not a new allocation

Using the **historical** assumptions of $0.12/M input and $0.80/M output, an input
reservation of 32768 and output reservation of 8192 gives $0.01048576 per call.
One initial attempt plus three arms and three draws would reserve **$0.62914560
for six components** if all initial attempts fail; the previous hypothetical
34-candidate design would reserve $3.56515840. These are planning examples, not
powered samples or current provider quotes. Neither fits the remaining
$0.34536941 of the current authorization. No partial prefix is launched.

Before a new collection: qualify source diversity, freeze the failed-checkpoint
rule, complete cohort and analysis, confirm current provider limits/prices, and
obtain a full authorized allocation. Original buggy sources are not themselves
model-generated failed repairs. Generation allowances are only part of total
resources; diagnostic and verification executions and failed requests remain
accounted separately. Cumulative commitment remains **$0.25463059 / $0.60**,
including fourteen historical uncertain reservations. No API calls, upstream
execution, new bug content or model results were generated by this audit.

## Reproduce

```bash
uv run experiments/python-repair/checkpoint-environment/results/token-capacity-20261030/reproduce.py
```

The script's inline metadata pins `tokenizers==0.22.2`, `jinja2==3.1.6` and
`transformers==4.57.1`;
`uv` may download those tools on first use. The measurement itself is offline:
it verifies archived tokenizer bytes, rebuilds all source artifacts and public
package projections from existing evidence, cross-checks every token sequence and
chat template through `AutoTokenizer` with local files and remote code disabled,
checks text/token round trips, and
compares all token counts, fingerprints and arithmetic with `analysis.json`.
No model weights or remote Python implementations are loaded, and candidate
source is treated as text. `tokenizer-assets.zip` contains only the official
tokenizer, two templates/configuration and model card; attribution and the
Apache-2.0 license are retained. Existing banks are unchanged.

The next source decision is recorded in [SOURCE-DIRECTION.md](SOURCE-DIRECTION.md).
Neither this capacity audit nor six development components establish diagnostic
benefit, an independent replication or a useful selector.
