## One-use launch and failure disposition

Commit source, pass the full offline workflow and exact-commit CI, then freeze
source commit, protocol/config/prior-report hashes and exact request bodies.
Use a fresh output directory and exclusive fixed study claim. Perform the
read-only endpoint/credit preflight; preserve no credentials or balance values.
Admit each request durably before dispatch. A complete response requires stable
model/provider/generation identity, one candidate, a terminal finish, a validated
usage receipt and `[DONE]`. Output truncation with a complete receipt is still a
billed observation, separately labeled by finish reason.

The first transport, protocol, identity, billing or source failure stops the
probe. Every uncertain request retains its full reserve or a larger observed
charge. Never retry, replace, resume or launch a successor. Later fixtures stay
unadmitted. A stopped process cannot be mistaken for completion; terminal audit
keeps all three planned fixtures. No intervention occurs on interim outcomes.

The adapter accepts UTF-8 split across reads, SSE line endings/multiline data,
keep-alives and the repeated finish reason on the accounting frame. It rejects
midstream errors, identity drift, duplicate JSON keys, extra candidates, missing
usage/terminal markers and unexpected output modes. `[DONE]` ends one response;
subsequent bytes cannot cause a second settlement. The 1 MiB wire limit and
bounded lines/events prevent unbounded buffering. The 180-second idle timeout
and 300-second wall check at read boundaries are not a hard total deadline: a
blocked read may overrun by the idle timeout. No cancellation/refund is inferred.

Raw wire bytes and partial content remain in memory only. Persist safe timing,
counts, a wire digest and validated numeric cost; a complete receipt is marked as
reconstructed from SSE and has bearer echoes redacted after content assembly.
The wire digest is provenance, not a claim that original SSE bytes were archived.
An incomplete answer is not scored as a model failure.
